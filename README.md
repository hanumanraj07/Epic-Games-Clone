# Epic Games Website Clone – Gaming Marketplace UI (Educational Project)

A fully responsive and modern frontend clone of the Epic Games official website, built with **React.js** and **Vite**, focusing on the UI/UX of their game store, library layout, hero banners, and promotional sections.

⚠️ **Disclaimer:** This project is not affiliated with Epic Games or the Epic Games Store.
It is an educational, non-commercial, UI-only clone with no real purchasing or account features.

## 🚀 Project Tagline

A sleek and immersive UI clone of the Epic Games Store — built with React to practice real-world gaming marketplace design.

## 📘 Description

This project recreates the visuals and interface structure of the Epic Games Store, including:

- Landing page hero banners
- Featured games carousel
- Store/product listings
- Game detail layouts
- Login-style UI sections
- Clean and cinematic visual design

Everything is static or simulated — no backend, authentication, or real purchases.

## ✨ Features

- ✔ Epic Games–style hero banners & promotional sliders
- ✔ Modern gaming marketplace UI
- ✔ Fully responsive layout (desktop → mobile)
- ✔ Store page, Game Details mock UI, Header, Footer
- ✔ Smooth animations & hover effects
- ✔ Modular and reusable React components
- ✔ Clean folder structure

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd epic-games
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit the local server URL (usually `http://localhost:5173`).

### Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start the development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint to check for code issues |
